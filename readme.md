## 🗺️ AI Agent & Maze Evolution (CfC + GA)
Проект по соэволюционному обучению RL-агента на базе жидких нейросетей (CfC) в лабиринтах, динамически усложняемых Генетическим Алгоритмом. Поддерживаются исключительно квадратные лабиринты (вписанные в квадратную коробку).
------------------------------
## 🚀 Быстрый старт и установка

   1. Установка зависимостей:
   
   pip install -r requirements.txt
   
   2. Сборка C++ бэкенда (PyBind11):
   Соберите оптимизированную библиотеку ядра из папки:
   
   ai/fast
   
   3. Выравнивание путей среды:
   Для корректной работы относительных импортов обязательно выполните команду в корневой папке проекта:
   
   pip install -e .
   
   
💡 Примечание: Библиотека websockets не является обязательной для базового обучения модели и требуется только при запуске интерактивного инференса через Godot-клиент.

------------------------------
## 🧠 Архитектура нейросети (ai/model.py)
Модель построена на каскаде ОДУ-сетей и пространственного зрения:

* Экстрактор признаков: CNN (свёрточная голова).
(Примечание: Свёрточная архитектура добавлена недавно. Если вы хотите вернуться к полносвязной сети FNN, с которой обучение в некоторых сценариях шло стабильнее, изменить код обратно не составит труда).
* Память (Рекуррентные слои): Каскад из двух слоев CfC (Closed-Form Continuous-Time) жидких нейросетей.
* Выходные слои (Головы Актора и Критика): Полносвязные сети (FNN).

------------------------------
## 🏋️ Обучение и конфигурация
Запуск основного конвейера соэволюции и обучения агента:

python ai/training.py


* Чекпоинты нейросети автоматически сохраняются в папку ai/models.
* Поколения хромосом лабиринтов от ГА сохраняются в ai/generations.

⚠️ Важные замечания по настройке:

   1. Система наград: Текущая система наград в методе step() класса MazeEnvironment (ai/environment.py) плохо сказывается на поведении модели на масштабах больше 16×16 — она заставляет агента топтаться на месте («эффект маятника»). Настоятельно рекомендуется модифицировать логику наград, особенно для плавной работы Curriculum Learning (последовательного усложнения), который по умолчанию зашит в ai/training.py.
   2. Аппаратные мощности: Перед стартом обязательно скорректируйте параметры ресурсов в конфиге Ray под конфигурацию вашего процессора и видеокарты.
   3. Конфигурация: В большинстве случаев для изменения стартовой модели, параметров сетей или смены начального поколения лабиринтов придётся вручную править конфигурацию прямо в коде.

## 🛠️ Полезные инструменты (ai/utils)
В папке ai/utils собраны утилиты для визуализации и работы с данными:

* db.py — Конвертер данных. Превращает текстовые поколения хромосом ГА в полноценные конфигурации поколений лабиринтов.
(Если вам нужно сгенерировать всего один лабиринт, используйте модуль fast/bsc_core или прототип ai/bsc_prototype.py).
* demo.py — Генератор датасета лабиринтов. На основе хромосом создаёт графические изображения лабиринтов с четко отмеченными точками Старта и Финиша.
* render_inference.py — Локальный визуализатор. Отрисовывает структуру лабиринта и подсвечивает пройденную траекторию (путь) агента в нём.

📊 Внимание: Скрипты генерации изображений по умолчанию настроены под сетку лабиринта размером 128×128, но вы можете изменить эти константы под свои нужды в коде утилит.

## 🎮 Инференс и Godot-визуализация (Внимание!)
Для демонстрации поведения модели в реальном времени используется связка сетевых серверов и игрового движка.
## Порядок запуска:

   1. Откройте файл servers/ws_inference.py и вручную укажите путь к весам вашей обученной модели. Запустите его:
   
   python servers/ws_inference.py
   
   2. Запустите оркестратор сети (сетевые адреса HOST и PORT легко меняются через глобальные переменные в начале скрипта):
   
   python servers/ws_server.py
   
   3. Откройте и запустите основной проект Godot из папки client.

## Сборка демонстрационного лабиринта:
Для полноценной работы демонстрации желательно собрать Godot-проект из папки demo в готовый исполняемый файл под вашу систему (demo.exe, demo.x86_64 и т.д.) и поместить его в папку godot_builds в корне проекта.
🔥 ВАЖНЫЙ СОВЕТ ПО РАЗРАБОТКЕ: Клиент для демонстрации инференса на данный момент реализован крайне нестабильно («инвалидно»). Нейросеть не может корректно продемонстрировать через него свои ходы, а физическим персонажем внутри этого демо-лабиринта невозможно управлять вручную. Рекомендуется вообще удалить папку demo и ничего из неё не собирать, сосредоточившись на логах и утилитах рендеринга путей!
