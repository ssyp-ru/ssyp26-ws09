Для работы модели требуется установить библиотеки из requirements.txt.
websockets необязателен для работы и требуется только для инференса через клиент на godot.
Также запустите "pip install -e ." в этой папке для выравнивания среды.

Также для вышеупомянутого инференса, кроме "servers/ws_inference.py" (не забудьте указать путь к весам модели в коде) требуется запустить 
сервер "servers/ws_server.py"и клиент godot из папки client, к которому желательно (но необязательно)
собрать ещё и godot проект из папки demo для демонстрационного лабиринта.
(HOST и PORT легко меняются через глобальные переменные)

К сожалению система наград в методе step класса MazeEnvironment "ai/environment.py" плохо сказывается
на модели для лабиринтов больше 16 на 16 и заставляет модель топтаться на месте, так что можете попробовать её изменить.
Особенно полезно настроить её под Curriculum Learning (по умолчанию в "ai/training.py").

В папке "ai/utils" есть полезные инструменты:
    db.py - создаёт из поколений хромосом поколения лабиринтов. (если нужно получить всего один, используйте "fast/bsc_core" или "ai/bsc_prototype.py")
    demo.py - создаёт по поколениям хромосом изображения лабиринтов со стартом и финишем.
    render_inference.py - отрисовывает лабиринт и путь модели в нём.    

Однако модели для генерации изображений настроены под размер квадрата лабиринта 128 на 128, но это можно изменить.

Поддерживаются только квадратные лабиринты (лабиринты в квадратной коробке).

Модель нейросети ("ai/model.py"):
    CNN (поменял на CNN недавно, возможно c FNN обучалась даже лучше, поменять обратно не слишком трудно)
    CfC
    CfC
    Головы критика и актора:
	FNN

При обучении модели сохраняются в "ai/models", а поколения в "ai/generations".
Для обучения используйте "ai/training.py".

В большинстве случаев для изменения стартовой модели или поколения придётся лезть в код.
